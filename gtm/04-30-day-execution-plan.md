# 30-Day Execution Plan — From Today to 10 Paid Clients

Today = **Day 0 = 2026-05-14**. Target: **10 paid customers by 2026-06-13.**

This plan is opinionated and concrete. Every day has owners, actions, and
exit criteria.

---

## Roles (assumed two-person team)

- **F1 (Founder #1, e.g. Sandeep)**: outbound owner — cold email + LinkedIn DM + partnership outreach
- **F2 (Founder #2, e.g. Jeet)**: content + delivery owner — LinkedIn/X posts, Snapshot delivery, founder calls, partnership negotiation

If solo, time-box: 4 hours/day outbound, 2 hours/day delivery & content.

## Stop-loss tripwires

If any of these fires by end of Week 2, intervene immediately:

| Tripwire                                    | Intervention                                   |
|--------------------------------------------|------------------------------------------------|
| Cold email reply rate < 4%                  | Rewrite Email #1 — angle of hook is wrong       |
| LinkedIn DM response rate < 10%             | Re-record/rewrite the connection note           |
| Snapshot uploads < 15 by Day 14             | Channel mix is too cold — double partnership outreach |
| Snapshot → paid conversion < 10%            | Snapshot output PDF doesn't tease Deep Dive well — rewrite |
| Zero partnerships by Day 7                  | Personal warm intro path — ask 3 angels for intros to accelerators |
